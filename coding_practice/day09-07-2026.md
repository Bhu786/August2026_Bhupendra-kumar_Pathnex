**AWS Shield** ek **DDoS (Distributed Denial of Service) protection service** hai.

### Kya hai?

* AWS ki managed security service.
* Website ya application ko DDoS attacks se bachati hai.

### Kyu hai?

* Website ko down hone se bachane ke liye.
* Traffic attack ke time bhi application available rahe.
* Performance aur uptime maintain karne ke liye.

### Kab use karte hain?

* Jab application internet par publicly accessible ho.
* Agar EC2, ALB, CloudFront, Route 53 ya Global Accelerator use kar rahe ho.
* High-traffic websites, banking, e-commerce, APIs, gaming apps mein.

### Types

1. **Shield Standard (Free)**

   * Sab AWS customers ko milta hai.
   * Common network & transport layer DDoS attacks se protection.

2. **Shield Advanced (Paid)**

   * Large-scale DDoS protection.
   * 24×7 AWS DDoS Response Team (DRT).
   * Cost protection aur advanced monitoring.

### Interview Answer (30 sec)

> **AWS Shield is a managed DDoS protection service. It protects internet-facing applications running on services like CloudFront, Route 53, ALB, and EC2 from DDoS attacks. Shield Standard is free and provides basic protection, while Shield Advanced is a paid service that offers enhanced protection, detailed monitoring, and access to AWS DDoS experts.**

Image me **AWS WAF (Web Application Firewall)** ke key points diye gaye hain. Short aur interview-friendly explanation:

### AWS WAF Kya Hai?

AWS WAF ek **Web Application Firewall** hai jo **web applications ko Layer 7 (HTTP/HTTPS)** attacks se protect karta hai.

### Kyu Hai?

* Malicious web requests ko block karne ke liye.
* Web application ko common attacks se secure rakhne ke liye.

### Kab Use Karte Hain?

* Jab website ya API internet par ho.
* CloudFront, ALB, API Gateway, AppSync ke saath.

### Image ke Key Points Samjho

* ✅ **Customizable Rules** – Apne rules bana sakte ho (IP block, country block, rate limit).
* ✅ **SQL Injection Protection** – SQL Injection attacks ko rokta hai.
* ✅ **Cross-Site Scripting (XSS) Protection** – XSS attacks ko block karta hai.
* ✅ **Bot Protection** – Bad bots aur automated traffic ko filter karta hai.
* ✅ **Integrates with CloudFront, ALB, API Gateway** – In AWS services ke saath directly attach hota hai.
* ✅ **Real-time Logging** – Web requests aur blocked traffic ke logs deta hai.
* ✅ **AWS Lambda Integration** – Lambda ke through custom security actions automate kar sakte ho.

### AWS Shield vs AWS WAF

| AWS Shield                        | AWS WAF                                            |
| --------------------------------- | -------------------------------------------------- |
| DDoS attacks se protect karta hai | Web attacks (SQLi, XSS, Bots) se protect karta hai |
| Network/Transport Layer (L3/L4)   | Application Layer (L7 - HTTP/HTTPS)                |
| Traffic flood attacks             | Malicious HTTP requests                            |

### Interview Answer (30 sec)

> **AWS WAF is a Web Application Firewall that protects web applications from common Layer 7 attacks like SQL Injection, Cross-Site Scripting (XSS), bots, and malicious HTTP requests. It integrates with CloudFront, ALB, and API Gateway, allowing us to create custom security rules, rate limiting, IP blocking, and real-time logging to secure internet-facing applications.**

### Amazon GuardDuty Kya Hai?

**Amazon GuardDuty** ek **intelligent threat detection service** hai jo AWS account aur resources ko continuously monitor karke suspicious activities detect karta hai.

### Kyu Hai?

* Security threats ko automatically identify karne ke liye.
* AWS environment ko hackers aur unauthorized access se bachane ke liye.

### Kab Use Karte Hain?

* Jab production AWS environment ho.
* Security monitoring aur compliance ke liye.
* Multi-account AWS setup mein.

### Image ke Key Points Samjho

* ✅ **Continuously Monitors** – AWS account aur resources ko 24×7 monitor karta hai.
* ✅ **Uses Machine Learning & Threat Intelligence** – ML aur AWS threat intelligence se suspicious behavior detect karta hai.
* ✅ **Provides Actionable Findings** – Security findings deta hai jisse issue fix kar sakte ho.
* ✅ **Integrates with CloudWatch/EventBridge** – Findings ke basis par automatic actions trigger kar sakte ho (Lambda, SNS, etc.).
* ✅ **Detects Unauthorized Access & Data Exfiltration** – Stolen credentials, reconnaissance (scanning), aur data theft attempts detect karta hai.

### Data Sources

* **CloudTrail Logs** → Suspicious API calls
* **VPC Flow Logs** → Suspicious network traffic
* **DNS Logs** → Malicious domains se communication
* **EKS, S3, EC2 Runtime Monitoring** → Container aur storage security

### Interview Answer (30 sec)

> **Amazon GuardDuty is an intelligent threat detection service that continuously monitors AWS accounts using CloudTrail, VPC Flow Logs, and DNS Logs. It uses machine learning and AWS threat intelligence to detect suspicious activities such as unauthorized access, reconnaissance, cryptocurrency mining, and data exfiltration. It generates security findings and can integrate with EventBridge and Lambda for automated response.**

### AWS Security Services Difference

| Service              | Purpose                                                            |
| -------------------- | ------------------------------------------------------------------ |
| **AWS Shield**       | DDoS protection (Layer 3/4)                                        |
| **AWS WAF**          | Protects web apps from SQL Injection, XSS, bots (Layer 7)          |
| **Amazon GuardDuty** | Detects security threats and suspicious activity                   |
| **AWS Inspector**    | Finds vulnerabilities in EC2, ECR, Lambda                          |
| **AWS Security Hub** | Central dashboard for security findings from multiple AWS services |

## AWS Inspector Kya Hai?

**Amazon Inspector** ek **automated vulnerability assessment service** hai jo AWS resources ko scan karke **security vulnerabilities aur misconfigurations** identify karta hai.

### Kyu Hai?

* Servers aur applications me security flaws dhoondhne ke liye.
* CVEs (Common Vulnerabilities and Exposures) detect karne ke liye.
* Patching aur security improve karne ke liye.

### Kab Use Karte Hain?

* Production EC2 instances.
* Container images (Amazon ECR).
* AWS Lambda functions.
* Compliance aur security audits ke liye.

### Key Points

* ✅ **Continuously scans** EC2, ECR, aur Lambda.
* ✅ **Detects vulnerabilities (CVEs)** aur missing patches.
* ✅ **Finds network exposure** (publicly accessible resources).
* ✅ **Provides risk score & recommendations**.
* ✅ **Integrates with EventBridge, Security Hub, and GuardDuty**.

### Kya Scan Karta Hai?

* **EC2** → OS vulnerabilities, missing security patches.
* **ECR** → Docker/container image vulnerabilities.
* **Lambda** → Vulnerable libraries and packages.

### Interview Answer (30 sec)

> **Amazon Inspector is an automated vulnerability management service that continuously scans EC2 instances, ECR container images, and Lambda functions. It identifies software vulnerabilities, missing patches, and network exposure, then provides risk scores and remediation recommendations to improve security.**

| Service              | Purpose                                          |

| **Amazon GuardDuty** | Detects suspicious activities and threats        |
| **Amazon Inspector** | Finds vulnerabilities and missing patches        |
| **AWS Security Hub** | Central dashboard for all security findings      |

### Easy Memory Trick

* **Shield** → **Protects** from DDoS.

* **GuardDuty** → **Detects** suspicious activity.
* **Inspector** → **Scans** for vulnerabilities.
* **Security Hub** → **Shows** all security findings in one place.

## 16. AWS KMS (Key Management Service)

### Kya Hai?

**AWS KMS** ek managed service hai jo **encryption keys create, store aur manage** karti hai. Isse AWS services me data encrypt/decrypt hota hai.

### Kyu Hai?

* Data ko secure rakhne ke liye.
* Encryption keys ko safely manage karne ke liye.
* Compliance aur auditing ke liye.

### Kab Use Karte Hain?

* S3 bucket encrypt karna.
* EBS volume encryption.
* RDS database encryption.
* Secrets aur sensitive data encrypt karna.

### Key Points

* ✅ Supports **Symmetric** aur **Asymmetric** keys.
* ✅ S3, RDS, EBS, Lambda jaise services ke saath integrate hota hai.
* ✅ **Automatic Key Rotation** support karta hai.
* ✅ IAM ke through **fine-grained access control** deta hai.
* ✅ CloudTrail me key usage audit hoti hai.

### Interview Answer (30 sec)

> **AWS KMS is a managed key management service used to create, manage, and rotate encryption keys. It integrates with services like S3, RDS, and EBS to encrypt data at rest. It also provides access control using IAM and auditing through CloudTrail.**

## 17. AWS Systems Manager (SSM)

### Kya Hai?

**AWS Systems Manager (SSM)** ek management service hai jo **EC2 aur on-premises servers ko remotely manage** karne, patch karne aur automate karne ke liye use hoti hai.

### Kyu Hai?

* SSH ke bina EC2 manage karne ke liye.
* Patching aur configuration automate karne ke liye.
* Multiple servers ko centrally manage karne ke liye.

### Kab Use Karte Hain?

* EC2 me login kiye bina commands run karna.
* OS patching.
* Software deployment.
* Configuration management.
* Inventory aur compliance check.

### Key Features

* ✅ **Session Manager** – SSH key ya port 22 open kiye bina EC2 access.
* ✅ **Run Command** – Multiple EC2 instances par ek saath commands run.
* ✅ **Patch Manager** – Automatic OS patching.
* ✅ **Automation** – Repetitive tasks automate karna.
* ✅ **Parameter Store** – Passwords, API keys aur configuration securely store karna.
* ✅ CloudWatch aur CloudTrail ke saath integration.

### Interview Answer (30 sec)

> **AWS Systems Manager is a service used to centrally manage AWS resources. It allows us to securely access EC2 instances without SSH using Session Manager, automate administrative tasks with Run Command and Automation, manage OS patches with Patch Manager, and securely store configuration values in Parameter Store.**

## 1. AWS RDS (Relational Database Service)

### Kya Hai?

Managed **SQL database service**.

### Kyu Hai?

* Database setup, backup, patching aur scaling AWS handle karta hai.

### Kab Use Karte Hain?

* Banking, E-commerce, ERP, CRM, Spring Boot applications.

### Supports

* MySQL
* PostgreSQL
* MariaDB
* Oracle
* SQL Server

### Interview Answer

> **AWS RDS is a managed relational database service that supports SQL databases like MySQL, PostgreSQL, Oracle, and SQL Server. AWS manages backups, patching, and scaling.**

---

## 2. Amazon Aurora

### Kya Hai?

AWS ka **high-performance relational database**, MySQL aur PostgreSQL compatible.

### Kyu Hai?

* RDS se faster aur highly available.

### Kab Use Karte Hain?

* High-traffic applications.
* Banking, SaaS, E-commerce.

### Features

* ✅ MySQL/PostgreSQL compatible.
* ✅ Auto scaling.
* ✅ Multi-AZ.
* ✅ High performance (up to **5× MySQL** and **3× PostgreSQL**).

### Interview Answer

> **Amazon Aurora is a high-performance relational database service compatible with MySQL and PostgreSQL. It provides better performance, scalability, and availability than standard RDS.**

---

## 3. Amazon DynamoDB

### Kya Hai?

Managed **NoSQL database** (Key-Value & Document database).

### Kyu Hai?

* Milliseconds latency.
* Auto scaling.
* Serverless.

### Kab Use Karte Hain?

* Gaming.
* IoT.
* Real-time apps.
* Chat applications.
* Shopping carts.

### Features

* ✅ NoSQL database.
* ✅ Serverless.
* ✅ Auto scaling.
* ✅ Very fast (single-digit millisecond latency).

### Interview Answer

> **Amazon DynamoDB is a fully managed NoSQL database that provides fast performance, automatic scaling, and serverless operation for applications requiring low latency.**
