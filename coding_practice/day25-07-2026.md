### Slide 2 — Why do we need this?

Imagine our production system:

```text
                API Gateway
                     │
        ┌────────────┼────────────┐
        ▼            ▼            ▼
      Order       Payment      Inventory
      Service      Service       Service
```

A user reports:

> **"Payment API is very slow."**

We need to know:

```text
Is CPU high?
Is memory high?
Are requests increasing?
Is error rate increasing?
Is API latency high?
What exception happened?
Which service caused the problem?
```

**Say:**

> "Without observability, we would have to manually check different servers and log files. With these tools, we can quickly identify where the problem is."

### Slide 3 — Prometheus: Collect Metrics
> "Prometheus is responsible mainly for metrics. It uses a pull model, meaning Prometheus periodically calls the application's metrics endpoint and stores the resulting time-series data."
```text
Spring Boot
     │
     │ /actuator/prometheus
     ▼
Prometheus
```

Spring Boot exposes metrics using:

```text
Actuator + Micrometer
```

Example metrics:

```text
HTTP request count
HTTP latency
JVM memory
CPU
GC
Database connections
```

Prometheus periodically **scrapes** these metrics.


### Slide 4 — Grafana: Visualize Metrics
> "Grafana does not replace Prometheus. Prometheus stores and queries the metrics, while Grafana connects to Prometheus and provides dashboards and visualizations. We can use PromQL queries to create panels for request rate, error rate, latency, CPU and JVM memory."


```text
Prometheus
     │
     │ PromQL
     ▼
  Grafana
     │
     ▼
 Dashboard
```

### Slide 5 — ELK: Centralized Logging
**ELK Stack:** Elasticsearch = Search/Analytics → Logstash = Collect/Transform → Kibana = Visualize/Explore.


**ELK Flow:** Logstash → Collects & Processes/Enriches Logs → Elasticsearch → Stores & Indexes JSON Documents → Kibana → Queries, Visualizes & Creates Dashboards.

**ELK Architecture:** Data Sources → Logstash (Collect + Filter) → Elasticsearch (Store + Index) → Kibana (Visualize & Analyze).

**ELK Use Cases:** Log Management → Real-Time Analytics → Security Monitoring → APM (performance/errors) → Business Intelligence (KPIs & dashboards).
