

Here are the key concepts taught throughout the session:

---

## 1. Kubernetes Cluster Setup on AWS EKS

* **AWS EKS Provisioning:** Step-by-step practical setup of an Elastic Kubernetes Service (EKS) cluster on AWS.
* **IAM Roles & Policies:** Configuring required Identity and Access Management (IAM) roles and access policies for EKS control plane and node management.
* **Control Plane & Node Groups:** Setting up worker nodes, defining node groups, and configuring Auto Scaling Groups (ASG) behind the cluster.
* **Version Support & Upgrades:** Understanding the difference between AWS EKS **Standard Support** and **Extended Support** for Kubernetes versions.

---

## 2. Kubernetes Architecture & Component Overview

* **Control Plane vs. Worker Nodes:** How the Kubernetes control plane interacts with and manages worker nodes.
* **Core Primitives:** Overview of how Pods, Services, and node components collaborate within a running cluster.

---

## 3. Kubernetes Scaling Strategies

* **Horizontal Pod Autoscaling (HPA):** Scaling workloads horizontally by dynamically increasing or decreasing the number of Pod replicas based on metrics (like CPU/memory).
* **Vertical Pod Autoscaling (VPA):** Scaling workloads vertically by dynamically adjusting CPU and memory resource requests/limits assigned to containers.
* **Difference between HPA and VPA:** When and why to use horizontal scaling vs. vertical scaling in production environments.

---

## 4. Security & Access Control Concepts

* **Authentication vs. Authorization:** Explaining the distinction between verifying user/service identities (Authentication) and granting permission to perform actions (Authorization) within AWS and Kubernetes.
