### **Key Kubernetes Concepts**

* **Control Plane (Cluster Brain):**

  * **API Server:** Entry point for all Kubernetes communication.
  * **etcd:** Stores the cluster state and configuration.
  * **Scheduler:** Assigns Pods to the best available worker node.
  * **Controller Manager:** Maintains the desired state of the cluster.

* **Pod:**

  * The smallest deployable unit in Kubernetes.
  * A Pod can contain one or more containers that share the same network and storage.

* **Cloud vs On-Premises:**

  * **Cloud (EKS, GKE, AKS):** Uses a Cloud Controller Manager to integrate with cloud services like Load Balancers and Storage.
  * **On-Premises:** No Cloud Controller Manager; infrastructure is managed manually.

* **Backups:**

  * **Velero** is commonly used to back up and restore Kubernetes resources and persistent volumes.
  * In managed Kubernetes services, direct access to **etcd** is typically not available, so providers manage its backups internally.
