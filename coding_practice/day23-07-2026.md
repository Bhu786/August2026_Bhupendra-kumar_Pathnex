CI/CD means automating the software delivery process.

CI — Continuous Integration
Developer writes code
Pushes code to Git
Automatically build and test the code
CD — Continuous Delivery / Deployment
After testing, application is prepared for deployment
It can be deployed automatically to servers or cloud

Simple example:

Developer → Git → Build → Test → Deploy
====================================
CI = Build & Test CD = Release & Deploy
======================================
CD CD : 
| **Continuous Delivery**                                                   | **Continuous Deployment**                        |
| ------------------------------------------------- | ------------------------------------------------ |
| Code is automatically **ready for production**               | Code is automatically **deployed to production** |
| May require **manual approval** before production      | **No manual approval**                           |
| Human can make the final deployment decision             | Pipeline deploys automatically                   |
| More **control and safety**                                             | More **speed and automation**                    |
