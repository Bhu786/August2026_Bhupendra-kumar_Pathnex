
# I Learned Today

1. **AWS Landing Zone**

   * Learned that it creates a secure multi-account AWS foundation using AWS Organizations, IAM, networking, logging, and governance.

2. **AWS Control Tower**

   * Learned that it automatically sets up, manages, and governs the Landing Zone using guardrails and a centralized dashboard.

3. **AWS Session Manager**

   * Learned how to securely access EC2 instances **without SSH keys, Port 22, Bastion Host, or Public IP**.

4. **Route 53, CloudTrail & CloudWatch**

   * Learned that:

     * Route 53 handles DNS and traffic routing.
     * CloudTrail records API activities for auditing.
     * CloudWatch monitors resources, collects metrics/logs, and sends alarms.

5. **AWS Lambda (Serverless)**

   * Learned that Lambda runs code automatically in response to events without managing servers and scales automatically.
